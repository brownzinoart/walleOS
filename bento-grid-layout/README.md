# Bento Grid Layout

A Pen created on CodePen.

Original URL: [https://codepen.io/emilandersson/pen/NPWLEpg](https://codepen.io/emilandersson/pen/NPWLEpg).

🎨 Beautiful Bento Grid with Pure CSS
This project showcases a clean and modern Bento-style grid layout built entirely with CSS—no JavaScript needed! The grid is fully responsive, using flexbox and CSS grid, with smooth spacing and elegant rounded corners.

✨ Features:

Grid-based layout for dynamic card positioning

Soft shadows & gradients for a sleek, modern look

Adaptive card sizes to enhance visual hierarchy

Customizable background images & colors for a polished aesthetic

Perfect for portfolios, dashboards, or landing pages, this design keeps things minimal yet eye-catching. 🚀
